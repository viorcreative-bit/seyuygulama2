Menü fiyatlarını güncelleyin

Buradan yaptığınız değişiklikler sitedeki menüye, favorilere, kahvaltı ve nargile bölümlerine yansır. Giriş için GitHub erişim anahtarınızı girin.

Erişim anahtarı nasıl alınır?
  1. GitHub'a giriş yapıp yeni erişim anahtarı sayfasını açın.
  2. Token name: "Nonna fiyat paneli" gibi bir ad yazın. Expiration: en uzun süreyi seçin; süre dolunca yeni anahtar oluşturmanız gerekir.
  3. Repository access: "Only select repositories" seçip seyuygulama2 deposunu ekleyin.
  4. Permissions → Repository permissions → Contents: "Read and write" seçin.
  5. Generate token deyip çıkan anahtarı kopyalayın ve yukarıya yapıştırın.

Anahtar yalnızca bu tarayıcıda saklanır. Ortak kullanılan bir bilgisayardaysanız "beni hatırla" kutusunu kapatın.
